# Windows-11-Workstation-Deployment
Windows 11 workstation deployment, Active Directory integration, endpoint security configuration, system maintenance, and troubleshooting.

## Project Overview

This independent technical project focuses on the installation, configuration, security, maintenance, and troubleshooting of Windows 11 workstations.

The project demonstrates practical experience with Windows operating systems, Active Directory integration, user account management, Group Policy, endpoint security, and system troubleshooting.

The primary objective was to establish functional, secure, and reliable workstation environments suitable for daily business operations.

## Project Duration

October 2025 – January 2026

## Technologies Used

- Windows 11
- Active Directory
- Group Policy
- Microsoft Defender
- BitLocker
- Windows Firewall
- Windows Update
- Command Prompt


## Project Objectives

1. Install and configure Windows 11 operating systems on workstations.
2. Configure user accounts and access permissions.
3. Integrate Windows 11 workstations with Active Directory.
4. Apply Group Policy settings to support centralized workstation management.
5. Implement endpoint security using Microsoft Defender, BitLocker, and Windows Firewall.
6. Perform operating system maintenance and software updates.
7. Troubleshoot operating system, application, hardware, and network connectivity issues.
8. Validate workstation functionality and network connectivity.
## Project Implementation

### 1. Windows 11 Deployment

Installed, configured, and upgraded Windows 11 operating systems on workstations, establishing functional endpoint environments and improving system readiness for daily operations.

### 2. Active Directory Integration

Configured Windows 11 workstations for Active Directory domain integration, managing user accounts, access permissions, and Group Policy settings to support centralized administration and consistent system configurations.

### 3. Endpoint Security

Implemented endpoint security controls, including Microsoft Defender, BitLocker encryption, and Windows Firewall, strengthening workstation security and protecting systems against unauthorized access.

### 4. System Maintenance

Performed system maintenance, software updates, and operating system troubleshooting, identifying and resolving configuration and application issues to maintain reliable workstation performance.

### 5. Troubleshooting and Validation

Tested hardware, software, and network connectivity to ensure reliable workstation performance.

## Project Outcome

This project strengthened my practical knowledge of Windows 11 deployment, Active Directory integration, endpoint security, system maintenance, and technical troubleshooting.

It provided hands-on experience with workstation administration and common IT support procedures.
